Project information

Prometheus unified monitoring and control platform

Prometheus stands out in my portfolio because it combines the parts of engineering I want to lean into professionally: backend reliability, safe execution workflows, visible runtime state, and operational clarity. The platform includes agent registration, heartbeat tracking, metrics ingestion, alerts, recurring schedules, control-plane APIs, and live monitoring over WebSockets.

It also reflects practical DevOps thinking instead of just feature development. The stack uses PostgreSQL and Redis, supports Celery workers and beat scheduling, exposes health-oriented interfaces, and organizes the system so automation can be audited and extended safely. That mix of infrastructure awareness, service orchestration, and production-minded design is the strongest representation of the role I am targeting next.
